## This repo contains hands on project from AWS builder.

## Project 1 ### https://github.com/nikita0150/AWS-Builder-Projects/tree/main/ai-recipe-generator
Serverless AI recipe generator built as an AWS Builder learning project. React + TypeScript app on AWS Amplify Hosting, authenticated with Amazon Cognito, using an AWS AppSync GraphQL API with a Bedrock HTTP data source to generate recipes with Amazon Bedrock (Nova Lite).
